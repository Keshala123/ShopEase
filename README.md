# M.A.K-E-COM

## Project Overview
M.A.K-E-COM is a static e-commerce website for Sri Lankan products, built using HTML, CSS, and JavaScript. It is a frontend-only project with no backend server, database, or payment processing implemented.

## Features
- Responsive design for desktop and mobile
- Product listing and detail pages
- Shopping cart UI (static, no real cart logic)
- Blog, About, and Contact pages
- Visual elements for payment (images only, no real payment integration)

## Limitations
- No backend (Node.js/Express not implemented)
- No database (all data is static)
- No user authentication or registration
- No payment gateway or order processing
- No real cart or checkout functionality

## How to Run
Simply open `index.html` in your browser. No installation or server required.

## Future Improvements (Suggestions)
- Add Node.js backend for dynamic product management
- Integrate a database (MongoDB/MySQL) for storing products and orders
- Implement user authentication and registration
- Add payment gateway integration (Stripe, Razorpay, PayPal)
- Enable real cart and order processing

## Security Considerations (For Future)
If backend and payment features are added, consider:
- Password hashing (bcrypt)
- JWT authentication
- Input validation and sanitization
- SQL injection protection (parameterized queries)
- CORS configuration
